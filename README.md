# Moroo — 个人 AI Prompt 灵感库

收集、分类、检索并一键复制高质量 AI 提示词的个人灵感库。纯前端实现，零依赖、零构建，数据完全保存在浏览器 localStorage 中。

## 功能

- **瀑布流灵感墙**：按图片原始宽高比排列（列宽 287px、间距 2px），卡片悬停浮现标题与操作
- **分类与筛选**：分类 tab 横向滚动（溢出带箭头）、排序（最新 / 标题 / 分类）、只看收藏
- **搜索**：标题、分类、标签、正文全文检索，防抖即时过滤
- **吸附筛选栏**：向下滚动吸附到顶部，向上滚动收起
- **详情查看器**：左侧大图舞台 + 右侧信息栏，支持复制 Prompt、收藏、下载原图、查看来源、相关推荐
- **新建 / 编辑**：封面图支持**图片链接**或**本地图片**（自动压缩至最长边 1600px 存入本地），自动测量图片尺寸按原比例展示；无图时按标题生成稳定的渐变封面
- **收藏**：卡片与详情页均可收藏，图标高亮即时反馈
- **导入 / 导出**：一键导出 JSON 备份，导入时按 id 合并去重，绝不覆盖已有数据
- **明暗双主题**：跟随系统，手动切换后记忆偏好

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `Cmd / Ctrl + K` | 聚焦搜索框 |
| `N` | 新建 Prompt |
| `Esc` | 关闭弹层 / 下拉 |

## 快速开始

无需安装任何依赖，任选其一：

```bash
# 直接用浏览器打开
open index.html

# 或启动一个静态服务
python3 -m http.server 8642
# 访问 http://localhost:8642/
```

## 数据说明

- 数据存储于浏览器 `localStorage`（键名 `prompt-library:v1`），不依赖任何后端
- 换设备或清理浏览器缓存前，请先在页面底部「导出全部数据」备份；导出的 JSON 可直接再导入恢复
- 本地图片以压缩后的 dataURL 形式保存，受 localStorage 容量（约 5MB）限制，大量图片建议改用图片链接

## 技术栈

原生 HTML / CSS / JavaScript，无框架、无构建工具、无 CDN。

实现要点：

- CSS 自定义属性令牌化管理双主题色板
- 瀑布流：按列宽计算列数 + 最短列优先分配，卡片比例来自图片实测尺寸
- 筛选栏吸附：滚动方向检测 + 固定占位高度，避免布局跳动
- Hero 动态点阵：双层点阵漂移 + 光标跟随光斑与视差位移
